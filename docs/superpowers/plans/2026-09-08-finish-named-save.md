# 이름 기반 저장소 변환 마무리

**Goal:** 원본을 보존하면서 사용자가 삭제했다고 확인한 세 모듈을 제외한 V2 복사본을 완성한다.

**Architecture:** 기존 리허설 CLI에 반복 가능한 `--exclude-module-id ID`를 추가한다. 삭제 대상을 추측하지 않고 입력 DB에서 존재를 확인한다. 활성 모듈과 소속·활성화 참조만 정리하며 원래 파일은 스냅샷과 변환 휴지통에 보존한다. V2의 entity-order 기록으로 삭제된 파일이 목록 재생성에서 부활하지 않는지 검증한다.

**Tech Stack:** Node.js 파일 저장소, Vitest, 기존 HTTP 호환 테스트.

- [x] `save-migration-rehearsal.test.ts`: 명시된 삭제 대상만 제외, 잘못된 ID 거부, 원본 불변, 삭제 파일을 다시 놓아도 재시작·index 복구에서 제외되는 테스트를 먼저 작성하고 실패 확인.
- [x] `canonical-import.cjs`, `rehearse-save-migration.cjs`: 확인된 삭제 ID 적용과 보고서 기록을 최소 구현. 관련 테스트 실행.
- [x] 기존 격리 스냅샷을 새 `migration-test-20260908-v2-final` 출력으로 변환. 모든 데이터 왕복·해시 검증을 유지하고 결과를 실제 서버에서 재시작 검증.
- [x] 사용자 문서·최신 패치노트에 명시적 제외와 성공 결과 반영. 원본 전환·커밋·릴리즈는 하지 않는다.

결과: `migration-test-20260908-v2-final/report.json`에서 89,016개 원본 스냅샷 파일 불변 및 전체 객체 왕복·재개방 일치를 확인했다. 캐릭터 31, 대화 60, 메시지 852, 활성 모듈 16, 프롬프트 10을 보존했다. `server-verification.json`에서 두 차례 독립 서버 기동의 데이터 읽기·삭제 모듈 부재·모듈 이미지 바이트 일치·정본 불변을 확인했다. 검증 서버는 종료했다. 서버/호환/모듈 회귀 테스트 197개 통과, 실물 fixture 5개 제외, 화면 빌드 성공.
